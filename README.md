# HyeonSaengTime

## 이번 작업: 홈/방 UI와 자정 결과 MVP 정리

스크린샷 레퍼런스를 기준으로 홈, 방 만들기, 설정, 결과 모달의 화면 톤을 맞추고, 목표 시간 정책을 16시간 고정으로 정리했습니다.

## 변경 내용

- 홈
  - 오늘 현생 시간, 연속일, 16시간 목표 진행 상태를 카드 중심 화면으로 표시합니다.
  - `onboarding.svg` 레퍼런스에 맞춰 홈 카드 마진, 반지름, 미션 카드 높이, 멤버 원 크기를 조정했습니다.
  - 첨부 SVG의 잎/타깃/멤버 원 크기를 벡터 리소스와 Compose 크기로 반영했습니다.
  - 방 멤버 활성 표시는 누적 시간이 아니라 현재 진행 중인 잠금 세션 기준으로 적용합니다.
  - 큰 타이머는 초 단위, 목표/멤버 시간은 `HH:mm`으로 표시합니다.
  - 방 멤버 목록의 내 시간은 홈의 현재 현생 시간을 우선 표시합니다.
  - 방이 있으면 날짜별로 고정 선택된 오늘의 방 미션과 방 멤버 현황을 함께 보여줍니다.
  - 방이 없으면 1인 상태와 방 만들기 진입 버튼을 보여줍니다.

- 방 만들기
  - 방 이름 중심의 생성 화면으로 정리했습니다.
  - 닉네임은 개인 설정값을 사용하고, 익명 여부는 방 생성 후 설정에서 다룹니다.
  - 약속 프리셋과 초대 코드는 현재 MVP에서는 표시 UI로만 둡니다.

- 설정
  - 하루 목표 설정을 제거했습니다.
  - 닉네임, 방장용 익명 표시, 복귀 알림 설정만 유지합니다.
  - 저장 버튼은 성공 시 홈으로 돌아가고, 방이 있으면 설정에서 방 나가기를 할 수 있습니다.
  - 기존 `daily_goal_hours`, `user_anonymous` 저장값은 legacy 값으로 cleanup합니다.

- 결과
  - 자정 이후 앱 화면에 들어오면 어제 결과를 하루 한 번 모달로 표시합니다.
  - 결과 모달은 개인 목표, 방 미션, 방 레벨, 방 내 순위를 함께 보여줍니다.

- 앱 아이콘
  - `icon frame.svg`의 로고를 Android launcher foreground와 fallback vector icon으로 적용했습니다.

## 방식과 이유

- 개인 목표/streak 기준은 `HyeonSaengRules.STREAK_REQUIRED_HOURS`의 16시간만 사용합니다.
- 앱 폰트는 system sans 기반 Typography로 통일하고, 자간을 0으로 맞췄습니다.
- Pretendard 파일이 앱 리소스에 없어서 CSS font stack은 Android 기본 sans 계열로 대응했습니다.
- 예전 목표 설정값은 제품 의미와 맞지 않아 더 이상 읽거나 쓰지 않고 제거합니다.
- 방/알림/기록 계산 로직은 유지하고, 이번 작업은 UI 정리와 잘못된 설정값 제거에 집중했습니다.
